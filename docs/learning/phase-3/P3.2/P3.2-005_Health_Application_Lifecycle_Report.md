## 3. Health Architecture

The new health and readiness architecture is structured as follows:

```
            [FastAPI ASGI Container]
                       │
       ┌───────────────┼───────────────┐
       ▼               ▼               ▼
  GET /health/live  GET /health/ready  GET /health/details
  (Liveness Probe)  (Readiness Probe)  (Detailed Telemetry)
       │               │               │
       │               ├───────────────┤
       ▼               ▼               ▼
  [HealthService] ◄── [DatabaseCheck]  [StorageCheck]  [ConfigurationCheck]
       │
       ▼
 [Standardized JSON Response] (UP or DOWN status)
```

---

## 4. Liveness Flow

1. **Endpoint Access:** Container orchestrators query `GET /health/live`.
2. **Uptime Check:** Verifies that the ASGI container is up and running.
3. **Payload Return:** Instantly returns `{ "status": "UP", "uptime": str, "version": str, "timestamp": str }` alongside backward-compatible checks dictionary.

---

## 5. Readiness Flow

1. **Endpoint Access:** Probes query `GET /health/ready` before forwarding traffic.
2. **Dependencies Checks:** Database connect checks are executed alongside uploads directory write verifications.
3. **Payload Return:** Returns `200 OK` with individual status entries if healthy, or `503 Service Unavailable` with details if any subsystem is DOWN.

---

## 6. Startup Sequence

1. **Process Load:** Python executes `app/main.py`.
2. **Boot Start:** Invokes `run_startup()` in [startup.py](file:///e:/TaskSyncEnterprise/backend/app/lifecycle/startup.py).
3. **Logger Setup:** Configures file rotating handlers and plain/JSON structured formatters.
4. **Validations:** Runs `validate_startup()` verifying limits, secrets, paths, and database ping.
5. **Lifespan Entry:** FastAPI starts and enters context lifespan, printing details to uvicorn streams.

---

## 7. Shutdown Sequence

1. **Termination Event:** Server intercepts `SIGTERM` / `SIGINT` signals.
2. **Lifespan Exit:** Lifespan context closes, triggering `run_shutdown()` in [shutdown.py](file:///e:/TaskSyncEnterprise/backend/app/lifecycle/shutdown.py).
3. **Database Disposal:** Disposes the SQLAlchemy engine connection pool.
4. **Log Flush:** Logs the shutdown action, flushes remaining log records, and calls `logging.shutdown()`.
5. **Process Exit:** Container terminates cleanly.

## 9. Performance Impact

*   **Fast Liveness:** Liveness probe does not query databases or filesystem mounts, resolving in $<1$ ms.
*   **Throttled Readiness:** Readiness check utilizes `HEALTH_TIMEOUT` configuration (3 seconds) to prevent ASGI thread locks.
*   **Lightweight Storage Checks:** Write verifications write small test strings to disk, introducing minimal I/O overhead.
