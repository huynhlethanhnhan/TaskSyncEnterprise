## 6. Architecture Improvements

The backend follows clean SOLID principles:
*   **Dependency Direction:** Database operations flow down through CRUD layer to engine objects. No reverse imports.
*   **Decoupled Layout:** Telemetry (`app/monitoring/`) is separated from the database engine and HTTP request scopes.
*   **Event-Driven Queries Monitoring:** Uses SQLAlchemy core listeners to time queries without injecting logic into router controllers.
