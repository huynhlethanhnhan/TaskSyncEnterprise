# Phase 1: REST API Routing & Core Concepts

Chào mừng đến với Phase 1 của chương trình học phát triển backend doanh nghiệp. Trong giai đoạn này, lập trình viên sẽ làm quen với các khái niệm định tuyến REST API cơ bản, cấu trúc gói tin HTTP và thiết kế dịch vụ hạ tầng tối thiểu.

---

## 🎯 Mục tiêu Học Tập
1. Hiểu cách thiết kế các tuyến endpoint chuẩn REST API.
2. Hiểu vai trò của các lớp phần mềm trung gian (Middleware).
3. Làm quen với Dependency Injection trong FastAPI.
4. Nắm vững bảng thuật ngữ backend doanh nghiệp tối thiểu.
