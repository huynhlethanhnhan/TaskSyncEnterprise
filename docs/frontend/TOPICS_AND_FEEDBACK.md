# TaskSyncEnterprise — Topics & Feedback Modules Specification

This document details the collaboration-focused workspaces for Topics and Feedback.

---

## 💬 1. Thảo luận chuyên đề (Topics)

- **Purpose:** Collaborative discussion boards for sharing team ideas.
- **Backend Gap:** No database schemas or router endpoints exist in the backend.
- **Frontend View:** Page details SQL Server DDL tables and proposed API endpoints.

---

## 🚦 2. Ý kiến phản hồi (Feedback)

- **Purpose:** Internal review system for product or operational suggestions.
- **Backend Gap:** No database schemas or router endpoints exist in the backend.
- **Frontend View:** Outlines categories (Product, Process, Culture, Tech) and status pipelines.
