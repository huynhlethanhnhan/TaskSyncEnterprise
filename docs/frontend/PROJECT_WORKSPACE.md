# TaskSyncEnterprise — Project Workspace Specifications

This document catalogs the tab-based workspaces within a project.

---

## 📐 Tab Layout Breakdown

- **Overview:** General workspace containing:
  - Completion progress bar indicator (`Done` task count / `Total` task count).
  - High-density KPI cards representing states (To Do, In Progress, Done).
  - Basic details (Project Code, Status, Start Date).
  - Recent activity log and member list.
- **Tasks:** Tabulated layout displaying project tasks. Allows changing assignee and editing descriptions inside the sidebar task detail view.
- **Kanban Board:** High-density board layout divided into three columns ("To Do", "In Progress", "Done").
- **Backlog & Sprints:** Technical placeholders detailing schema blueprints and backend gaps.
- **Calendar:** Displays a monthly calendar filtered specifically for tasks in the current project.
- **Files & Discussions:** Shared resources directories displaying details about missing backend endpoints.
