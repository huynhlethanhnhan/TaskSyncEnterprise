# TaskSyncEnterprise — Final Manual Acceptance & Demonstration Guide

## Executive Summary

This guide provides step-by-step instructions for the project owner and academic evaluators to perform a manual end-to-end acceptance test of TaskSyncEnterprise.

---

## 1. Prerequisites & Environment Setup

Ensure the following prerequisites are available on the local machine:
- Python 3.12+ (Virtual environment in `backend/.venv`)
- Node.js 18+ & npm
- MS SQL Server 2019+ or LocalDB running locally
- Google Chrome browser

---

## 2. Server Startup Instructions

### Step A: Launch Backend Service
Open Terminal 1 (Powershell):
```powershell
cd E:\TaskSyncEnterprise\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --reload
```
*Verify Health Endpoint*: Navigate to `http://127.0.0.1:8000/health` (Should return `{"status": "healthy"}`).

### Step B: Launch Frontend Application
Open Terminal 2 (Powershell):
```powershell
cd E:\TaskSyncEnterprise\frontend
npm run dev
```
*Verify Web Portal*: Navigate to `http://localhost:5173`.

## 4. Step-by-Step Acceptance Checklist

### A. Administration Workflow
1. Log in as **Admin** (`admin@tasksync.com` / `TaskSync@2026`).
2. Navigate to **Phong ban & Team** (`/departments`).
3. Verify existing Departments (e.g. `Engineering`, `Product`, `HR`).
4. Click **Tạo phòng ban**, fill Name & Code, click Save.
5. Create a new Team under the Department. Verify Team correctly links to the parent Department.

### B. Employee Management Workflow
1. Navigate to **Nhân sự** (`/employees`).
2. Click **Thêm nhân sự**.
3. Observe that `Mã nhân viên` is automatically generated by the backend (`EMP-YYYYMMDD-XXX`).
4. Select Department, then select Team (Notice Team dropdown only presents teams belonging to the chosen Department).
5. Click Save. Verify new employee appears with active status.

### C. Work Manager Workflow (Project & Members)
1. Navigate to **Dự án** (`/projects`).
2. Click **Tạo dự án mới**.
3. Select **Phòng ban** (e.g., `Engineering`).
4. Observe **Team** dropdown enables and lists teams belonging to `Engineering`.
5. Enter Code `PRJ-ACCEPT-01` and Name `Release Candidate Demo`. Click Save.
6. Open the newly created Project detail page (`/projects/{id}`).
7. In the **Thành viên** tab, add `manager@tasksync.com`, `developer1@tasksync.com`, and `developer2@tasksync.com`.

### D. Agile Sprint & Task Management Workflow
1. In the Project detail page, switch to **Sprints** tab.
2. Click **Tạo Sprint mới** (`Sprint 1`), set Start/End dates, click Save.
3. Switch to **Công việc** tab (`/tasks`). Click **Tạo công việc mới**.
4. Select Project `Release Candidate Demo`. Select Sprint `Sprint 1`.
5. Select Assignee (Observe Assignee dropdown only presents active ProjectMembers).
6. Save Task.
7. Open **Bảng Kanban** (`/board`) and drag task between `To Do` -> `In Progress` -> `Done`.

### E. Role-Based Scope & Security Verification
1. Log out Admin. Log in as **Employee 1** (`developer1@tasksync.com` / `TaskSync@2026`).
2. Open **Công việc của tôi** (`/my-tasks`).
3. Update task status and progress percent. Verify update succeeds (200 OK).
4. Attempt to modify restricted fields (Title/Priority). Verify frontend disables input or backend blocks with 403 Forbidden.
